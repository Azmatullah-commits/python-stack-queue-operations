## 1. Stack

Stack follows the LIFO principle.

The last element added is the first element removed.

### Stack Operations

- push(): Add an element
- pop(): Remove the top element
- peek(): View the top element
- is_empty(): Check if stack is empty
- display(): Show all elements

## 2. Queue

Queue follows the FIFO principle.

The first element added is the first element removed.

### Queue Operations

- enqueue(): Add an element
- dequeue(): Remove the first element
- front(): View the first element
- is_empty(): Check if queue is empty
- display(): Show all elements

## How to Run

Make sure Python is installed.

Run the Stack program:

```bash
python stack.py
```

Run the Queue program:

